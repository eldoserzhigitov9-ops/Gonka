# 🏁 Жарыс: сұрақ-жауап

Квиз-гонка для двух игроков (казахский / русский язык). Учителя регистрируются, создают
собственные наборы вопросов, делятся ими по коду или открывают всем. Данные хранятся в
**Supabase**, код — в **GitHub**, сайт хостится на **Vercel**. Сборка не нужна — это обычный статический сайт.

```
index.html          страница игры
css/style.css       стили
js/game.js          игра (машинки, вопросы, звук)
js/teacher.js       кабинет учителя + работа с Supabase
js/config.js        ← сюда вставляются ключи Supabase
assets/             картинки и звуки
supabase/schema.sql структура базы данных и правила доступа (RLS)
vercel.json         настройки хостинга
```

## Как это работает

- **Играть** может кто угодно, без регистрации: меню → «Сұрақтар / Вопросы» → выбрать открытый набор или ввести код.
- **Учитель** регистрируется (email + пароль), создаёт наборы, добавляет вопросы на двух языках
  (достаточно заполнить один — на другом покажется тот же текст).
- Набор **открытый** — виден всем в библиотеке, любой учитель может «Копировать себе».
  Набор **закрытый** — доступен только владельцу и тем, кому он даст 6-значный код.
- Менять и удалять наборы может только их владелец — это обеспечивает Row Level Security в базе.
- Если Supabase не настроен или недоступен, игра работает на встроенных 21 базовых вопросах.

## Установка (≈ 20 минут)

### 1. Supabase (база данных и вход)
1. На [supabase.com](https://supabase.com) создайте проект (регион — ближайший, запомните пароль БД).
2. **SQL Editor → New query**: вставьте всё содержимое `supabase/schema.sql` → **Run**. Запускать нужно один раз.
3. **Project Settings → API**: скопируйте **Project URL** и ключ **anon / public** (или «publishable»).
4. Откройте `js/config.js` и вставьте их. Ключ `anon` публичный по задумке (защиту дают правила RLS из `schema.sql`).
   **Ключ `service_role` сюда вставлять нельзя.**
5. **Authentication → Providers → Email**: решите, нужно ли подтверждение почты.
   Встроенная почта Supabase отправляет лишь несколько писем в час, поэтому для школы проще
   **выключить «Confirm email»**, либо подключить свой SMTP (Authentication → SMTP Settings).

### 2. GitHub
```bash
cd race-quiz
git init
git add .
git commit -m "Жарыс: первая версия"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/race-quiz.git
git push -u origin main
```
(Репозиторий предварительно создайте на github.com → New repository, пустой.)

### 3. Vercel
1. На [vercel.com](https://vercel.com) войдите через GitHub → **Add New → Project** → выберите репозиторий.
2. Framework Preset: **Other**. Build Command и Output Directory оставьте пустыми. Нажмите **Deploy**.
3. Через минуту сайт будет доступен по адресу вида `https://race-quiz-xxxx.vercel.app`.

### 4. Последний шаг в Supabase
**Authentication → URL Configuration**: в **Site URL** впишите адрес вашего сайта на Vercel
(и добавьте его в Redirect URLs). Без этого ссылки из писем (подтверждение почты, сброс пароля) будут вести не туда.

Готово: отправьте ссылку учителям. Обновления — `git push`, Vercel выкатит их автоматически.

## Что полезно знать
- **Бесплатный тариф Supabase** «усыпляет» проект после недели без активности. Он включается обратно
  кнопкой в панели; данные не теряются.
- Библиотека `supabase-js` подключается с CDN (jsDelivr) с зафиксированной версией `2.45.4`.
- Любой человек может зарегистрироваться как учитель. Если нужно ограничить — в Supabase отключите
  открытую регистрацию и создавайте учителей вручную (Authentication → Users → Add user).
- Лимит — 300 вопросов в наборе (меняется в `schema.sql`, функция `limit_questions`).
- Идеи для развития: статистика матчей, импорт вопросов из Excel/CSV, изображения в вопросах, перемешивание нескольких наборов.
